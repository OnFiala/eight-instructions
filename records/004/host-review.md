# Changed host boundaries — same-author review

Reviewed by sole Astra xHigh. Manifest hashes make later edits visible; they do
not prove semantics or constitute an independent audit.

| Component | Responsibility and review conclusion |
| --- | --- |
| `tools/emitter.py`, `kernel/build.py` | Emit actual bounded BF context-copy/clear computation and generic region capacity. They consume no candidate program or city solution. |
| `runtime/system.mjs`, `tools/reference.c` | Bounded 160MiB source ingress for the larger kernel. The reference still executes the literal eight commands. |
| `runtime/cli.mjs` | Adds selection of a raw source manifest through `--autonomous`. No Thread parsing or city decision. Conflicting boot profiles are refused. |
| `tools/materialize-kernel.mjs` | Losslessly expands the tracked gzip, verifies identity and the eight-command alphabet. It does not regenerate an application answer. |
| `dist/autonomy-presentation.mjs` | Length-framed source decoding and native world tags prevent trial output from entering live rendering. No score recomputation or acceptance selection. |
| `dist/industry-ui.mjs` | Raw `autonomy-step` transport, user drafts, controls, queued bridge input, opaque export/import, native evidence presentation. BF itself chooses trial participants, horizons, goals and decisions. Import uses a candidate worker before replacing the live worker. |
| `dist/industry-scene.mjs`, CSS and HTML | Render native entities/roads/materials and optional inspection. Camera geometry, decorative surroundings and raster asset placement have no inventory or planning authority. Interpolation uses only adjacent observed states. |
| `tools/build-industry-image.mjs` | Actually compiles the raw autonomous sources in BF and records a round-zero image. No candidate decision or simulated round is precomputed. |
| `tools/build-autonomous-reproduction.mjs` | Test/evidence harness executes real BF inputs and captures expected output. Assertions belong to verification and never enter production imports. |
| `tools/package-reproduction.mjs` | Deterministic ZIP file transport with fixed metadata. Bundles actual inputs, runtime and evidence. |
| `tools/measure-synthesis.mjs` | Timings of raw BF input, component probes and ordinary native acceptance. Labels the publication call's combined cost rather than presenting it as an isolated compile timing. |
| `tools/check-browser-transcript.mjs` | Replays actual raw browser input in a fresh machine and compares output bytes. Supports an explicitly supplied restored image. |
| `tools/build-archives.mjs` | Preserves Build 003 assets from its immutable tag, with documented HTML navigation relocation. Historical source/kernel content is not upgraded. |
| `tools/audit.mjs` | Checks the decompressed released BF bytes even when ignored raw materialization is absent. Every executable/presentation component remains classified. |
| CI partition | Covers every test file exactly once. Isolates synthesis stress and literal context execution into jobs with the existing 90-minute ceiling; no assertions or limits removed. |

No production dependency or external model API was added. WABT remains pinned at
1.0.39 for generic executor assembly. Test-only raw inputs, fault injection and
expected output are absent from the browser's production import graph.
