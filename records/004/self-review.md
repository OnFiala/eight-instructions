## Findings addressed

1. Trial compiler and city output could be mistaken for live output. The separate
   length-framed parser consumes complete source bodies and world markers before
   the older live parser runs. Spoofed native text inside source stays source.
2. A stock guard around old combined `work` would also prevent offering already
   available material. Native `make` and `offer` separate those actions, while old
   `work` retains its established behavior.
3. Additional validation can finish after the real goal. Native freshness rejects
   that publication; the failed test expectation and subsequent fixture correction
   remain recorded. The guard was not weakened to force an acceptance.
4. A nonreturning candidate might receive credit for cargo already in flight.
   Native root-return and recent-return requirements disqualify that trial.
5. Protected observation originally checked only the selected factory. It now
   checks every faulted process using the published module. Repair uses the process
   handle, including a peer without an industry entity. Material remains owned.
6. Construction appends directions sharing an occupancy counter. Odd existing
   road counts or a duplicate in either direction now refuse before allocation.
7. Large administrator-configured supplies could overflow unsigned fitness
   arithmetic. Search now refuses supply ≥16,384; scoring also bounds raw stock and
   installed material. The native test asserts refusal before a context is created.
8. Invalid import retained the machine but hid its error in a closed inspector.
   Visible status feedback now reports the refusal. Import validates a new worker
   and only then replaces the current machine.
9. A queued bridge input could remain pending after exact BF continuation resumed,
   or outlive a world replacement. Resume now flushes it at the readable boundary;
   accepted import/reset cancels host inputs belonging to the old instance.
10. Mobile inspector intrinsic height hid lower controls. A bounded dynamic viewport
    height provides internal scrolling; opening/Escape preserve keyboard focus.

## Practical limits and remaining release gates

One initial construction plan is data; it is not a universal city planner. Sixteen
grammar candidates, four automatic searches and finite capacities limit what can
be discovered. A different objective may prefer a different rule. Arithmetic,
conservation and liveness checks do not prove absence of every possible program
regression. Fault injection and unseen fixtures are finite evidence.

Automatic native work takes seconds. Browser animation is presentation, and a
hidden/closed tab does not become a running server. Manual drafts and queued UI
inputs are separate from committed native machine state. Older images require
their historical kernel. Image integrity is not authentication.
