## Limits and unrun checks

- Four named modules, six version arenas, 256-byte source, 128-word module code; live dependencies and pins can exhaust capacity.
- One rollback version, bounded serials and 16-bit arithmetic. Reclamation covers module arenas; resident general Thread remains monotonic.
- Pure module profile, 64-value stack, 16 frames and 1024-instruction evaluation budget. General Thread developer access is trusted.
- Native cold workloads take seconds on the measured machine. Interpolation does not imply a higher simulation frequency.
- No traffic/collisions, backend, cloud autosave or image migration. Build001 keeps its matching old kernel.
- Images preserve native state, not the full historical presentation log. The inspector labels unavailable earlier costs.
- No Safari, physical-phone, full screen-reader, 200% text-zoom or complete WCAG audit; viewport emulation and specified keyboard checks only.
- Finite tests and same-author review are not a proof of arbitrary programs or a security boundary against editing one's own tape.

A possible later challenge is native storage management for unrestricted resident Thread definitions. It is only a proposal, not an approved or implemented Build003. No backend or adjacent service was added.
