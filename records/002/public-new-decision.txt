  - heading "A useful system from eight instructions." [level=2]
  - heading "Thread gives you words." [level=3]
  - paragraph:
    - text: Brainfuck moves a pointer, changes a cell, reads or writes a byte, and loops. Its eight instructions are
    - code: "> < + - . , [ ]"
    - text: . The BF kernel implements Thread, a small stack language. Build 002 adds a source workspace, typed module compilation, exact version links and reclaimable memory in Thread, executing inside that kernel.
  - paragraph: When you apply a rule, BF stores the text, checks it, compiles a candidate and publishes a new version. Invalid source leaves the working version in place. One rollback version is retained; live calls and dependencies retain what they still need. Freed arenas can be used again.
  - heading "The host makes it visible." [level=3]
  - paragraph: Python builds the initial BF kernel from an auditable generator. A generic JavaScript/WebAssembly executor runs the eight instructions. JavaScript sends raw input, saves opaque machine images and renders the BF output. It does not compile your module, solve routes or advance the city on its own.
  - paragraph: The architecture and vehicle images are generated graphical assets. Roads, paths, counters and positions come from the running program. Smooth motion interpolates between observed positions; native logical steps can take seconds.
