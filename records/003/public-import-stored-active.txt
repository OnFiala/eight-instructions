  - heading "Eight instructions. Programs that cooperate." [level=2]
  - heading "Thread makes the programs readable." [level=3]
  - paragraph:
    - text: "The Brainfuck programming language has eight instructions:"
    - code: "> < + - . , [ ]"
    - text: . They move a pointer, change a cell, read or write a byte, and loop. The BF kernel implements Thread, a small stack language used for the city's programs.
  - paragraph: Build 003 adds resumable processes, bounded message queues and a deterministic scheduler inside BF. Depots, factories, vans, stations and traffic signals run distinct programs. BF also owns inventory, routes, road reservations and construction.
  - paragraph: Source is stored and compiled inside BF. Old suspended calls keep their version. New invocations adopt an accepted update. A declared incompatible state/message schema is refused. Freed contexts and version arenas can be reused.
  - heading "The host executes and draws." [level=3]
  - paragraph: Python emits the initial BF kernel. A generic JavaScript/WebAssembly executor runs its eight instructions. JavaScript carries raw input, stores opaque machine images and draws native output. It does not schedule guest processes, deliver their messages, compile their rules or simulate the city.
  - paragraph: Architectural images are graphical assets. Materials, cargo, phases of construction and routes are selected from actual BF output. Smooth movement interpolates only between observed positions. This is logical concurrency in one BF machine, not a full operating system or self-hosting.
  - paragraph: "Resources are finite: sixteen processes, four messages per mailbox, eight modules and sixteen version arenas. Native work can take seconds; camera movement remains available while it computes."
